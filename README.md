# VR Club - Single Page Application

Веб-приложение для VR-клуба на Vue.js 3, c административной панелью и личным кабинетом пользователя.

## 🚀 Технологии

- **Vue.js 3** - основной фреймворк
- **Vue Router 4** - маршрутизация
- **Vuex 4** - управление состоянием
- **Axios** - HTTP-клиент
- **Bootstrap 5** - UI-фреймворк
- **Swiper** - слайдеры и карусели
- **Vue Plyr** - видеоплеер
- **Vue The Mask** - маски ввода

## 📁 Структура проекта

```
src/
├── api/              # API-клиенты (auth, adminFeed, axios)
├── assets/           # Статические ресурсы (изображения, видео, иконки)
├── components/       # Vue-компоненты
│   ├── adminPanel/  # Компоненты административной панели
│   ├── cabinet/     # Компоненты личного кабинета
│   ├── homePage/    # Компоненты главной страницы
│   ├── modalWindows/# Модальные окна (логин, регистрация)
│   └── UI/          # Переиспользуемые UI-компоненты
├── data/            # Данные и конфигурации
├── helpers/         # Вспомогательные функции
├── router/          # Конфигурация маршрутизации
├── store/           # Vuex store и модули
└── views/           # Страницы приложения
```

## 🎯 Функциональность

### Публичные страницы
- **Главная** (`/`) - многоэкранная презентация клуба с видео и слайдами
- **О нас** (`/about`) - информация о клубе
- **Цены** (`/price`) - прайс-лист
- **Акции** (`/promotions`) - текущие акции и предложения
- **Бронирование** (`/reservation`) - форма бронирования

### Пользовательские функции
- **Личный кабинет** (`/cabinet`) - просмотр бронирований (требует авторизации)
- **Авторизация/Регистрация** - модальные окна с валидацией

### Административная панель
- **Админ-панель** (`/admin`) - управление контентом (требует прав администратора)
  - Управление категориями
  - Редактирование элементов категорий
  - CRUD-операции через API

## 🛠️ Установка и запуск

### Требования
- Node.js (рекомендуется версия 16+)
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Разработка
Запуск dev-сервера с hot-reload:
```bash
npm run serve
```
Приложение будет доступно по адресу `http://localhost:8080`

### Сборка для production
```bash
npm run build
```
Собранные файлы будут в папке `dist/`

## ⚙️ Конфигурация

### Переменные окружения
Создайте файл `.env` в корне проекта для настройки API:
```
VUE_APP_API_BASE_URL=http://your-api-url.com
```

### Vue Router
Маршруты настроены в `src/router/index.js`. Реализованы:
- Защита маршрутов (требование авторизации/админ-прав)
- Редирект на страницу ошибки для несуществующих маршрутов

### Vuex Store
Модули состояния:
- `auth` - управление авторизацией
- `adminFeed` - данные административной панели
- `dialogWindow` - управление модальными окнами
- `globalModule` - глобальное состояние (загрузка и т.д.)

- Проверка прав доступа для административной панели
